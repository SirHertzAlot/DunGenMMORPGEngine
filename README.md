# DunGenMMORPGEngine

Deterministic, server-authoritative, procedurally generated MMORPG engine.

- Unity client (`projects/5`), ASP.NET Core 10 backend (`services/authoritative`),
  docker-compose infra, GitHub Actions CI.
- The wiki lives in [`docs/`](docs/index.md). Start at the **[Wiki Home](docs/index.md)**.
- Live status and verified facts: **[`docs/STATUS.md`](docs/STATUS.md)**.

Root folder is kept clean on purpose — the codebase is under `services/`, `projects/`, and `docs/`.
